# Made on the Web — Personalized Task 1

Personalized for Muthu Manojkumar T.I, an Electrical and Electronics Engineering student who likes pink.

## Project files
- `index.html` — page structure, content, navigation, technology cards and About Me section.
- `style.css` — pink editorial theme, typography, layouts, decorative code illustration and responsive media queries.
- `script.js` — personal welcome alert and rotating creative ideas.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `WebCraft_Personalized_Task1` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Click **Say hello** and **Give me a tiny idea**.
5. Resize the browser to test the mobile layout.

## Internship Task 1 coverage
- HTML: headings, paragraphs, links, navigation and semantic sections.
- CSS: pink color palette, typography, spacing, cards and responsive layout.
- JavaScript: button click events and alert/message interaction.
